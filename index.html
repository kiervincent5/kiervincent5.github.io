Featured Capstone Project

SMC EcoDrop — Smart Plastic Bottle Recycler

An automated IoT recycling station that identifies students via a UART QR code scanner, validates deposited plastic bottles using inductive & capacitive proximity sensors, and measures bin capacity with an HC-SR04 ultrasonic sensor. Data is transmitted via an ESP8266 Wi-Fi module to a Python & Django web app that dispenses rewards and delivers real-time administrative analytics.
